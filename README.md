# MetalVlug

An original 2D run and gun for the browser. Pip and Juno of the Lantern Brigade push through Lowtide Docks to free the captured Tinkers and break the Rustcoats' rolling fortress, the Iron Warden.

Mechanics follow the arcade run and gun genre (one hit kills, tap to shoot, knife up close, limited special weapons, a rideable walker, hostage rescue score). World, characters, art, music and levels are original.

## Run it

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

| Script | What it does |
|--------|--------------|
| `npm run dev` | Vite dev server |
| `npm run build` | Type check and production build into `dist/` |
| `npm test` | Unit tests (Vitest) |
| `npm run test:e2e` | Browser tests with real key presses (Playwright) |
| `npm run assets` | Regenerate the pixel art atlas, fonts, backgrounds and baked effects |
| `npm run audit` | Check the art against the style guide |

On Windows run Vitest from an uppercase `C:\` path.

## Controls

| Action | Keyboard | Gamepad |
|--------|----------|---------|
| Move, aim up, crouch | Arrows or WASD | Stick / D pad |
| Fire (knife when close) | J or Z | X |
| Jump | K, X or Space | A |
| Bomb | L or C | B |
| Leave the Mule | Up + Jump, or E | Y |
| Launch the Mule | Up + Jump + Fire | |
| Pause | Esc or P | Start |

## What is in it

- Mission 1, Lowtide Docks, with the Iron Warden boss, and a Training Camp tutorial.
- Two playable soldiers with different perks.
- Rivet gun, Scatter cannon, Thumper, bombs, the Mule walker.
- Original chiptune soundtrack and synthesized sound effects.
- Options for music, sound, screen shake, flashes and an easy mode, saved locally.

## Stack

Phaser 4, TypeScript 7, Vite 8, Vitest 5, Playwright. Art is generated by code in `tools/sprites`; explosion and impact effects are baked at build time from [pixelfx](https://github.com/patch-gg/pixelfx).
