# Credits

MetalVlug is a non-commercial portfolio project by Marvel Collin ([marvelcollin.com](https://marvelcollin.com), [github.com/MarvelCollin/MetalVlug](https://github.com/MarvelCollin/MetalVlug)).

Game design, code and pixel art are original. The game is inspired by the run and gun genre; it uses no sprites, music, sound or levels from any existing game. Music and sound come from the free licensed packs below.

## Everything else

Characters, enemies, vehicles, tiles, backgrounds, items and the font are original and generated by the code in `tools/`.

## Effects

- Explosion and impact effects in `public/assets/fx.png` are rendered at build time by `tools/fx/bake.mjs` from [pixelfx](https://github.com/patch-gg/pixelfx) (commit 5294518), MIT licence, Copyright (c) 2026 patch-gg.
- pixelfx adapts [Sprite Fusion's open source pixel art VFX](https://www.spritefusion.com/pixel-art-vfx), MIT licence, Copyright (c) 2026 Hugo Duprez.
